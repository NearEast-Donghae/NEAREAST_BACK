# 백엔드 검증 기록

2026-11-19 로컬 개발 환경. API http://localhost:8012/docs, PostgreSQL pgvector/pgvector:pg17.

## 확인된 결과

- 최종 전체 187개 테스트 통과. 실제 PostgreSQL 통합 17개를 포함합니다.
- PostgreSQL 통합 17개 통과: 인증·사용자 소유권·여행 수정 이력·동시 채팅 중복 방지·pgvector 저장 및 cosine distance.
- Alembic upgrade 후 `alembic check`: 모델과 실제 DB 차이 없음.
- 한국철도공사 실제 API: 2026-11-14 동해역 운행 기록 63건 응답 확인. 전체 스냅샷을 새 키로 재수집한 것은 아닙니다.
- 원래 knowledge/*.md 20개 본문과 DB body가 20/20 일치합니다. 원문 파일 20개와 참조 JSON 3개는 삭제했습니다.
- 실제 OpenAI `text-embedding-3-small` 호출로 문서 20개 적재. 벡터 20/20개가 1536차원이고 제목+본문 해시도 20/20 일치합니다.
- 실제 DB 컬럼은 vector(1536). 임베딩 파일은 생성·Git 저장하지 않습니다.
- gpt-5.4-nano 실제 호출 3건: 모두 mode=llm, fallback 없음. 응답 저장 총 6개 메시지, 같은 requestId 재전송 시 추가 생성 없음.

위 결과는 연결·저장 검증이며 모든 질문의 사실성·추천 품질 통과를 뜻하지 않습니다.
`live-verification.log`에는 테스트 질문의 상세 결과를 남기며 Git에서 제외합니다. 생성한 테스트 사용자는 정리했습니다.

재시작한 8012 서버에서도 실제 LLM mode=llm, 메시지 저장 201을 추가 확인했습니다.

공개/인증 정책: 비로그인 장소·열차 조회 200, 챗봇·계획 조회 및 생성 401을 확인했습니다.

## 원천 데이터의 한계

- 장소 14개 모두 좌표 없음. 지도에 실제 표시할 좌표를 공공 원천에서 보강해야 합니다.
- 지식 문서 20개 모두 sourceUrl 없음. 현재 sources 배열의 값은 내부 문서 id이며 검증된 외부 링크가 아닙니다.
- 예: 논골담길/묵호역 원문은 인접 관계 한 문장, 망상해수욕장은 상세 정보 미확인 문장입니다.
- 열차는 실제 운행 기록에서 가공한 특정 토요일 추정 스냅샷이며 실시간 운행·좌석·지연 데이터가 아닙니다.
- 망상 통과 시각은 선로 거리 기반 보간값입니다. 임의 여행 날짜에 대한 운행 보장은 없습니다.
- 기존 스냅샷의 열차 1861 등 일부 구간은 서로 다른 주차 기록 혼합 때문에 시각 정합성 재검토가 필요합니다.
- 기존 mock/fallback 도구의 인근 도보 시간·예시 시간표는 그대로 남아 있습니다. 실제 데이터로 오해하면 안 됩니다.
- 챗봇의 자연어 여행 온보딩과 완성된 LLM 루트 생성기는 아직 구현 범위 밖입니다.

## 파일 용도

서비스 참조용 MD/JSON은 제거했습니다. README와 docs/*.md는 개발 문서,
tests/chat_scenarios/scenarios.json은 테스트 입력입니다. data/raw/는 API 수집 재시도용 로컬 캐시이며 Git/Docker에서 제외합니다.
alembic/seed/0002_reference.sql은 최초 PR 자료 이관용 고정 seed입니다. 운영 중 조회·갱신 자료는 DB에 저장합니다.
임베딩이 정상이어도 원문에 없는 좌표·운영시간·역사·실시간 휴장 정보를 만들어내지는 못합니다.
