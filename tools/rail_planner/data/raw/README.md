# 원본 데이터

원본 CSV와 인증된 API 응답에서 가져온 스냅샷을 이 폴더에 둡니다.
원본과 생성 데이터는 기본적으로 로컬에 보존합니다.

| 입력 | 파일명에 포함할 문자열 | 범위 |
|---|---|---|
| 동해시 관광명소 | 관광명소현황 | 관광지 |
| 동해시 여객터미널 | 여객터미널정보 | 교통거점 |
| 국가철도공단 철도역 | 철도역 정보 | 전국에서 동해시만 선별 |
| 한국철도공사 동해선 | 동해선_역 위치정보 | 도시철도 역 위치 조사 |
| 동해시 패밀리사이트 | 패밀리사이트 | 웹사이트 목록 |

CSV는 UTF-8 또는 CP949를 사용합니다. 같은 판본의 첨부 사본은 한 개만 둡니다.
검증한 장소 근거, 좌표 제외 목록, 추가 조사 목록은 `data/reference/`에 있습니다.
원본의 인코딩과 헤더는 `python -m scripts.import_csv`로 확인합니다.
